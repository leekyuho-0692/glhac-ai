# A. 공통 (인증 전) / Common

## A-1. 로그인 · 가입 / Login · Sign-up  `[auth]`
- **목적:** 계정 진입. 신규 기업 가입. 로그인 후 역할별 nav 노출.
- **노출:** 전체(비로그인).
- **레이아웃:** 중앙 카드(브랜드+폼) + 우측 소개 패널. 상단 우측 🌐 언어 셀렉트.
- **컴포넌트:** Form(ID/이메일·PW) · 로그인/가입 탭 · 언어 셀렉트 · (가입) 기업 기본정보.
- **데이터:** `User(username·role·org_id)` · `Org`.
- **상태:** error(자격 불일치·중복 가입 인라인) · loading(제출 버튼 스피너).
- **액션·권한:** 로그인·회원가입(공개).
- **API:** `POST /auth/login` · `POST /auth/register` · `GET /auth/me`.
- **AC:** 잘못된 자격 → 401 메시지 · 가입 후 온보딩 이동 · 언어 선택 로컬 저장.

## A-2. 온보딩 / Onboarding  `[onboarding]`
- **목적:** 신규 기업 초기 설정(프로필·할랄감독 등록·경로 안내) → 신청 진입.
- **노출:** 클(신규).
- **레이아웃:** ①기업 프로필 ②penyelia(할랄감독) 등록 ③경로 안내(SD/REG) + 시작 버튼.
- **컴포넌트:** Form · penyelia 등록 · 경로 가이드 카드 · Stepper(온보딩 진행).
- **데이터:** `CaseApplication(state=onboarding)` · `PenyeliaHalal`.
- **상태:** empty(가이드) · error(필수 누락).
- **액션·권한:** penyelia_add(클·컨·할랄감독) · 신청 시작.
- **API:** `POST /cases`(초안) · `POST orgs/{org}/penyelia`.
- **AC:** 자기선언 필수요건(penyelia) 미충족 경고 · 신청 화면으로 전이(`application_draft`).

# B. 내비게이션 화면 / Nav Screens (15)

## B-1. 대시보드 / Dashboard  `[dashboard]`  · 전 역할
- **목적:** 전 과정 현황을 지도·집계로 총괄 모니터링(역할별 스코프).
- **레이아웃:** (좌)인니 지도+세계 중첩 (우)단계별 집계·감사 이벤트·알림.
- **컴포넌트:** MapWidget(지역별 건수 드릴다운) · StatCards(단계 카운트) · AuditFeed · NotifyList.
- **데이터:** `CaseApplication`(집계) · `WorkflowEvent`(피드).
- **상태:** empty(데이터 없음 안내) · loading(카드 스켈레톤) · error(집계 실패 재시도).
- **액션·권한:** 지역 드릴다운 · 케이스 바로가기 · (운영자) 메시지/공지 전송.
- **API:** `GET /admin/cases`(admin) · 역할 스코프 집계 · `GET /admin/audit`.
- **리스트요건:** 위젯 내부 상위 목록(불필요-독립 리스트).
- **AC:** 역할별 스코프(조직/담당) 필터 · 지도 지역별 건수 정확.

- **컴포넌트:** **DataList**(정렬·필터·검색·페이지·행액션·CSV·역할 컬럼 게이팅).
- **데이터:** `CaseApplication`(id·product·pathway·state·owner·due·risk).

- **API:** `GET /cases`(역할 스코프) · `POST /cases`.

## B-3. 워크스페이스 / Workspace  `[workflow]`  · 클·컨·운·IT
- **목적:** 케이스 작업공간 — 상태 스테퍼 + 섹션 통합 + 다음 액션.
- **레이아웃:** 상단 Stepper(28상태) + (좌)섹션 링크 (우)다음 할 일.
- **컴포넌트:** Stepper(현재/완료/차단) · SectionNav(신청·원재료·SJPH·문서·심사·평가·청구·파트와·인증서) · NextActionCard.
- **데이터:** `CaseApplication.state` · `WorkflowEvent`(타임라인).
- **상태:** loading(타임라인) · error · 차단 상태(가드 미충족 사유 표시).
- **액션·권한:** "다음 단계로 진행"(전이 가드 검증) · 섹션 이동.
- **API:** `GET /cases/{id}/timeline` · 각 전이 API.
- **리스트요건:** 케이스별 1개(상위=caseList).
- **AC:** 상태별 다음 액션·담당·기한 정확 · 가드 미충족 시 진행 비활성+사유.

  - 용도: 할랄 규정·파트와 선례·유사 케이스·원재료 판정 근거를 장기기억에서 회수해 답변 정확도·근거 강화.
  - 흐름: `질문 → (케이스 단기문맥 + CHU-1 장기 top-k 검색) → 로컬 LLM 합성 → 출처 인용`.
  - 게이트: 장기기억 장애 시 로컬 문맥만으로 폴백(차단 없음). 민감정보는 집계/비식별만 저장(연동 §NFR 보안).
- **상태:** empty(예시 질문) · loading(검색+응답) · error(AI/장기기억 장애→수동 폴백 안내).
- **액션·권한:** ask·screen-text·doc-checklist(any auth). 장기 컨텍스트 조회(읽기).
- **API:** `ask`(→ CHU-1 검색 포함)·`ai/screen-text`·`doc-checklist`·`GET /ai/health` · **`GET /ai/context/health`(CHU-1)**.
- **리스트요건:** 불필요.
- **AC:** AI/장기기억 장애 시 진행 차단 없음 · 답변에 **장기기억 출처 인용** · 민감정보 비저장.
